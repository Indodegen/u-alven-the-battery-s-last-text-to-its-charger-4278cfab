Entry for the [make.fun bounty "The Battery's Last Text to Its Charger"](https://make.fun/bounty/u-alven-the-battery-s-last-text-to-its-charger-4278cfab).

The phone battery's final text message to the charger it waited for all day — one line, 60 characters:

> I survived the whole day on 1% just to ghost you first. Bye.

`main.ts` (Node 22) writes the line to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`), after checking it is 1–200 characters, a single line, and not whitespace only.
